# Conversación de Género (Traducción al Español)

Traducción al español del submod **Gender Conversation** para *Monika After Story*.

## ⚙️ Requisitos

Este submod *(al igual que el resto de mis traducciones de submods)* requiere **OBLIGATORIAMENTE** el siguiente helper para que las funciones de género y pronombres funcionen correctamente en español:
- [MAS Pronombres ES](https://github.com/CofKaf/mas-pronombres-es) (Descárgalo y colócalo en tu carpeta de submods).

## 💾 Instalación

Coloca la carpeta del submod en tu directorio del juego:
`DDLC/game/Submods/Gender Conversation/`

> **Nota:** Mantén esta estructura exacta para evitar conflictos con archivos de otros submods.

## 🔄 Conversación de Deadname (Opcional)

Si ya habías configurado tu nombre y quieres esta charla:
1. Crea un archivo llamado `dev_console.rpy` en `DDLC/game/` con el código para activar la consola.
2. En el juego, presiona `Shift + O`, escribe `jump mas_preferredname` y presiona Enter.
